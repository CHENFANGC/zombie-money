# Project Description

## Zombie Money

Zombie Money is a mobile-first consumer prototype that helps users “wake up” idle stablecoins instead of leaving them parked in their wallet.

The key insight is emotional, not technical:

Most DeFi earn products make users understand APY, vaults, and protocols before they understand why they should care.

Zombie Money starts with a simpler message:

**Your money is sleeping. Wake it up.**

## What it does

- Detects a mocked idle stablecoin balance
- Pulls real LI.FI Earn vault data
- Ranks stablecoin-friendly opportunities with trust-focused filtering
- Recommends one simple wake-up route
- Simulates a believable activation flow for a smooth demo experience

## Why it matters

This project is designed to make DeFi yield feel closer to a premium savings product than a protocol dashboard.

Instead of overwhelming the user with options, it gives them one confident recommendation and a clear sense of emotional payoff when funds become “awake.”

## LI.FI usage

- `earn.li.fi` is used as the source of truth for vault discovery
- Recommendation logic is built on normalized LI.FI Earn responses
- Composer execution is intentionally not fully integrated in this sprint, to preserve polish and demo reliability in one night
